The {marginaleffects} workflow

Every call makes three choices — quantity, grid, aggregation — and every call returns one data frame.

Fit the model
Estimate the coefficients
In
turnout (2000 respondents)
f <- vote ~ age +
  educate + income + race
fit <- glm(f,
  data = turnout,
  family = binomial)
Out
fit — the coefficient estimates β̂ and their variance matrix.
Coefficients aren't interpretable on their own → compute quantities of interest (invariance property + delta method).

What do we compute?
a Scale  ·  Intype =
Default probability scale. (comparisons() uses "response"; predictions() uses "invlink(link)" — same estimates, CI built on the link scale.)
Other "link" — linear predictor scale (rarely)

predictions()→ expected value, E(y | X)
comparisons()→ a comparison of two expected values, hi vs. lo
No default — you pick.

A recipe for one number per covariate row — e.g., “Pr(vote) at age 90 minus Pr(vote) at age 18.”

2 · Grid
Where do we compute it?
In newdata =
Default the observed data → one row per respondent (2000 rows)
Other built with datagrid(). Unspecified variables sit at their mean (mode for factors).
datagrid(type = "mean_or_mode")
the typical case1 row
datagrid(age = 18:90)
vary age, fix the others73 rows
datagrid(educate = c(12, 14, 16))
vary educate3 rows
datagrid(race = unique)
vary race2 rows
Out
A table of covariate rows; the quantity is computed once per row.
Tip: inspect the output to see the grid you actually used.

3 · Aggregation
One estimate per row, or a summary?
In which function you call
Default predictions() / comparisons()
Keep every row: one estimate per grid row, per contrast. Good for showing heterogeneity — plot them.
Other avg_predictions() / avg_comparisons()
Average the rows into one estimate; SE by the delta method (not mean() of the estimates' SEs).
Two named estimands (Hanmer & Kalkan 2013)
Average case = typical-case grid, then average (trivially, of 1 row)
